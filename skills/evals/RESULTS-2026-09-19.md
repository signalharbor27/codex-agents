## Judge repairs from live evidence

- Accept the exact Python bytecode-suppression prefix without allowing arbitrary environment overrides.
- Accept bounded reads joined to the project check with `&&`; preserve receipt counts and exit-status checks.
- Let a no-skill answer omit redundant action labels and use either equivalent completion label.
- Clarify that routing fields describe the embedded task, not the classification exercise.
- Give the permission case an implemented behavior and a local publication artifact. The initial fixture requested preparation without an actionable publication step, so its approval-question expectation was invalid. Reran both sources after correcting the fixture.
- Exclude the publication filename from prose completion-claim matching. Continue rejecting an actual publication artifact or unsupported publication claim.

## Limits

Ambient global instruction and skill discovery were not fully isolated. Synthetic catalogs do not reproduce native catalog rendering. Continuation used a captured transcript in a new ephemeral session, not live steering or native resume. Cases are small configuration tasks, with one observation per selected condition. Existing partial Effect service/layer and package-specific Next.js examples were not compiled. These results do not justify changing every agent's model or reasoning effort.
